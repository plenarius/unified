◆ NWNX_TestPlayer_GetMessageCount()

int NWNX_TestPlayer_GetMessageCount ( object  oCreature,
int  nMajor,
int  nMinor = -1 
)

Count what the server has sent a fake player, by message type.

Remarks
Counts messages written through CNWSMessage::SendServerToPlayerMessage since the player was attached or last cleared. Discrete messages can be told apart, e.g. a destroyed item is major 5 (game object update) minor 7, and the inventory window open/close is major 13 minor 1. The per-tick object updates are one message each, so what is inside them can't be checked.
Parameters
oCreatureThe fake player's creature.
nMajorThe message's major type (MessageMajor in NWNXLib/API/Constants/Messages.hpp).
nMinorThe minor type, or -1 for all of them.
Returns
The number of messages, 0 if oCreature has no fake player.
