◆ NWNX_Layonara_SetNWSyncAdvert()

int NWNX_Layonara_SetNWSyncAdvert ( string  sHash,
string  sUrl 
)

Change the NWSync manifest the server advertises, at runtime and without a restart.

Note
Every client that connects afterwards gets the new manifest; players already in the game keep what they downloaded. The manifest must already be published at sUrl and hold every hak and the TLK the module uses, or connecting clients fail their sync. Any additional manifests the server advertised are dropped.
Parameters
sHashThe primary manifest's SHA1: 40 hex characters.
sUrlThe NWSync repository URL, as for -nwsyncurl.
Remarks
Pass "" for both to stop advertising NWSync, as if the server had started without it.
Returns
TRUE if the advert changed, FALSE if sHash isn't a SHA1 or only one of the two is empty.
